## Technical Insights
- Alpine Linux uses OpenRC, not systemd, requiring `rc-service` commands instead of `service`
- OpenRC manages services via symlinks in `/etc/runlevels/` directories (boot, default, etc.)
- Docker can be configured during build by creating symlinks rather than running `rc-update` commands
- WSL environments may have timing issues with Docker daemon startup requiring wait loops
