## Technical Insights
- WSL path translation errors can be completely avoided using `wsl.exe -d <distro> --cd /`
- Alpine uses ash (BusyBox) as default shell, not bash - important for .profile vs .bashrc
- Variable substitution in heredocs requires unquoted EOF markers for expansion
- Modular bash libraries dramatically improve testability and code reuse
