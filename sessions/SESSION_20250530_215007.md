## Technical Insights
- Alpine 3.18 repositories don't contain tree-sitter packages despite documentation
- OpenRC requires manual initialization in WSL: mkdir -p /run/openrc && touch /run/openrc/softlevel
- Docker daemon can be started manually with: sudo dockerd > /dev/null 2>&1 &
- Claude Code installation belongs in OOBE phase, not build phase, for network access
- Modular approach (separate module files) better than duplicating entire build scripts

## Challenges Encountered
- Docker service wouldn't start with standard commands (Alpine uses rc-service, not service)
- OpenRC not properly initialized in WSL environment
- Tree-sitter packages caused build failures (removed all of them)
- Initial Claude Code installation attempts failed during build phase
