## Technical Insights
- Alpine's BusyBox passwd has hardcoded password policies that can't be configured
- Installing shadow package provides more configurable password management
- Pre-installed scripts in /usr/local/bin greatly improve user experience
- Tree-sitter packages have limited availability in Alpine repositories

## Challenges Encountered
- Password policy conflicts with BusyBox passwd requiring installation of shadow package
- Tree-sitter-comment and tree-sitter-ini packages don't exist in Alpine 3.18
- Passing passwords between WSL instances requires careful handling
