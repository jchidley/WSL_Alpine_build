## Technical Insights
- Alpine Linux uses BusyBox ash as default shell, not bash - critical for WSL startup
- Package operations requiring chroot can't run during build - must use OOBE scripts
- Test suites using DRY_RUN=1 only verify execution, not correctness
- Logging to stdout breaks command substitution - must redirect to stderr
- WSL requires exact shell paths in /etc/passwd for user login to work

## Challenges Encountered
- Initial build failures due to chroot permission denied errors
- WSL startup failures due to /bin/bash not existing in Alpine
- Test suite showed all passing but build still failed
- Command output capture included log messages, breaking functionality
